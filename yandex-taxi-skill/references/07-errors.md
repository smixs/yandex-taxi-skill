# 07. Коды ошибок и починка

Любой код ошибки = «Заказать» не нажимать.

| Код (выход) | Причина | Починка |
|---|---|---|
| ТОЧКА / ERR (2, 13) | место не задано или нули из шаблона | 04-setup: впиши PLACE_*, или дай lat,lon |
| LOGIN_LOST (3) | cookies слетели | 02-login-qr: новый QR, state-save |
| NO_TARIFFS (4) | тарифы не загрузились | подожди, повтори; проверь сеть и гео (01); точка вне зоны сервиса |
| NO_ALLOWED (5) | нет разрешённого тарифа | пришли владельцу список и цены, спроси |
| TARIFF_FAIL (6) | клик по тарифу не выделил его | повтори prepare; смотри скриншот; окно мешает - закрой модальное |
| CARD_FAIL (7) | карты нет в списке или подпись не совпала | 03-card; сверь `CARD_LABEL` с текстом кнопки |
| NO_ORDER_BUTTON (8) | кнопки «Заказать» нет | сделай `status`, посмотри экран; возможно заказ уже идёт |
| GEO_BLOCK (9) | капча/блок IP | 01-preflight: другой IP или машина |
| NO_BROWSER (10) | нет agent-browser | 01-preflight |
| NO_CONFIG (11) | нет config.env | 04-setup |
| NO_STATE (12) | нет файла входа | 02-login-qr |
| SAVE_FAIL (12) | демон agent-browser ответил "Resource temporarily unavailable" 3 раза | закрой сеанс (`close`), открой страницу заново, повтори state-save; рабочий state не тронут |

## Ловушки сайта
- Подсказка адреса перекрыта модальным окном: закрой его, потом клик. Не вышло - `eval` с `.click()` по `[role=option]`.
- Баннер cookies: «Allow essential cookies».
- Цены «от …» = без входа. Не верить.
- Нет скриншота или пустая страница: подожди дольше, `snapshot -i`, не повторяй бесконечные циклы ожидания.

## Если скрипт сломался
Почини в том же ходе (селекторы сайта меняются). Ручной путь: `agent-browser --session $SESSION state load`, `open` URL с `gfrom/gto`, `snapshot -i`, `find text "<Тариф>" click`, оплата, и только потом «Заказать».
